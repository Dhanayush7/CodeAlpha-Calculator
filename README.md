# 🧮 Advanced Calculator

A modern and responsive calculator built using **HTML, CSS, and JavaScript**. This project goes beyond a basic calculator by including scientific functions, calculation history, keyboard support, dark/light mode, and a stylish glassmorphism user interface.

## 🚀 Features

### Basic Calculator Operations
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage
- 🔢 Decimal Support

### Scientific Functions
- √ Square Root
- x² Square
- sin()
- cos()
- tan()
- log()

### User Experience
- 🌙 Dark/Light Mode Toggle
- ⌨️ Keyboard Support
- 📋 Copy Result Button
- 🗑️ Clear Screen
- ⌫ Delete Last Character
- 📱 Fully Responsive Design
- ✨ Smooth Hover Animations
- 🎨 Modern Glassmorphism UI

### History Management
- 📝 Calculation History
- 💾 Local Storage Support
- 🔄 Persistent History After Refresh
